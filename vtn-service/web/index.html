How to verify this network

Verify a member

Check whether a community or network is a member, from the evidence: the network's signed answer, the credentials it rests on, and the trust registry the network publishes to. No sign-in needed.

About this network's trust

Listing is one-sided: an entry is a member only once it has acknowledged the network's listing (VTI-VTN-013). Anything that cannot be determined is indeterminate, never "not a member" (VTI-REG-012).

Check it yourself

Independent of this page: nnm verify resolves the network's and the member's DIDs itself and verifies every signature.
